# AdTech Prime email signature images

Is repo mein sirf signature ki images hain (logo, icons, banners).
Ye `https://sig.adtechprime.in/assets/...` par public milti hain, taaki email padhne wale ko dikhein.

- Banner badalna ho: `assets/` mein usi naam ki nayi file upload karo. Sabke signature mein naya banner dikhega.
- Signature Studio (editor) yahan nahi hai, woh private Claude link par hai.
